# 文案：每个位置承担一项决策

## 先分工

| 位置 | 买家要判断什么 | 内容选择 |
| --- | --- | --- |
| 标题 | 是什么，是否符合需求 | 品牌、核心品类、关键结构或数量，必要差异点 |
| Item Highlights | 为什么值得进一步看 | 补充材质、场景、数量或关键边界，不复制标题 |
| 五点 | 我能放心买吗 | 可核对答案、证据、使用条件，每条一个中心 |
| 描述/A+ | 实际如何用，哪个版本适合 | 使用流程、规格、版本比较、品牌事实 |
| 后台词 | 还缺哪些相关表达 | 相关同义词和长尾词；不堆砌、不蹭竞品品牌 |
| 图片 | 能否一眼理解 | 把规格、结构、使用过程和边界可视化 |

## 标题与 Highlights

先保留商品身份和决定购买的结构信息，再决定差异点。不要截取旧标题的前 75 字符，也不要为了填满长度添加空泛形容词。品牌名、空格和标点都计入长度。

洗澡刷示例优先表达刷子类型、手柄结构和包装数量；尺寸、刷毛材质及触感只有确认后才加入。不借用其他商家的品牌、产品名称或图片作为本品事实。

Highlights 可用可读的短句或短语，但不能变成第二个关键词仓库。未确认该字段可用时，给独立候选文案并标记后台待核实，不擅自挪成另一条标题。

## 五点：问题 → 事实 → 使用边界

例如，买家问“一份有几支刷子？”时，回答已确认的包装数量及是否包含其他物品，比“Complete Set”更有帮助。

可按核心结构、使用方式、数量、护理收纳和限制排列。优先解决本次资料中的实际疑问，不强求固定顺序；事实不足时减少成稿条目，另列待补项。

短标题加简短说明；手机端能扫读。关键词自然分布，避免在每条重复同一品类。美国站优先常用美式英语和适当英制单位，必要时附公制；换算要注明精度，不改动原始测量值。

数字不足时不编造。看起来蓬松不代表刷毛柔软，刷毛材质不能自动证明适合敏感肌，日常洗澡用途也不能自动证明有抗菌或治疗功效。

## 描述、A+ 与后台词

描述/A+ 用于展开使用流程、版本差异和完整规格。关键限制、安装条件、数量不应只藏在 A+，前台短文案、图片及结构化属性也应一致。品牌故事只写用户提供的事实。

A+ 模块、尺寸、资格和显示方式按当前模板核实，不把旧的 970×600 当成通用格式，不把审核时长写成保证。

后台搜索词使用当前站点允许的字段与长度；UTF-8 字节数和字符数不同。去掉无关词、促销、ASIN、竞品品牌和无依据属性，减少不必要重复。不承诺某个词必然被收录或带来流量。
